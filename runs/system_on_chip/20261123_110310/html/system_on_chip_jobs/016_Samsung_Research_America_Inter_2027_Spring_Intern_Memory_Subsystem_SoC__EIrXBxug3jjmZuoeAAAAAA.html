Job description

About the position

The Samsung SOC Lab develops SoC architecture, bus and memory subsystems, multimedia subsystems, and key IP blocks for future Samsung Galaxy products. It works with Samsung’s strategic SoC partners, Samsung MX headquarters, and R&D teams around the world to develop high-performance SoC architectures for Galaxy devices.

The Memory Architecture team is seeking a motivated intern... to contribute to the design, development, and modeling of memory microarchitectures and subsystems. The intern will work alongside experienced engineers on performance models, architectural exploration, and analysis. Strong coding skills, computer architecture knowledge, and experience with performance modeling and analysis are desirable.

Responsibilities
• Develop, debug, and fix fabric and/or memory subsystem performance models, and assist with performance analysis.
• Collaborate with senior engineers on modeling and analysis to improve model accuracy.
• Perform use-case analysis with the model to support architectural exploration.
• Document model work, analysis, and results.
• Use industry-standard tools and/or create in-house tools for performance evaluation and analysis.
• Communicate progress and results in meetings and incorporate input from senior engineers.

Requirements
• Currently pursuing a Master’s or PhD degree in Electrical Engineering, Computer Engineering, or a related field.
• Proficiency in C or C++ programming languages.
• Coursework or experience in computer architecture, System-on-Chip, memory subsystems, and/or interconnects.
• Experience in microarchitecture modeling, simulation, and performance evaluation.
• Excellent problem-solving skills and ability to work in a fast-paced, collaborative environment.
• Legally authorized to work in the United States.
