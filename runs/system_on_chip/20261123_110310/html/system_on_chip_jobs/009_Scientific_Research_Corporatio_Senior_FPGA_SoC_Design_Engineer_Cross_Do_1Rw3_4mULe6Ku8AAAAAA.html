Description

We are seeking an experienced, autonomous Senior FPGA & SoC Design Engineer to serve as the FPGA Subject Matter Expert (SME) supporting crit...ical research and engineering initiatives for the Naval Research Laboratory (NRL).

In this role, you will lead the design, implementation, and verification of high-reliability programmable logic (PL) components targeting modern AMD/Xilinx Zynq UltraScale+ MPSoC platforms. Rather than standard RF/DSP mathematical signal processing, your primary focus will be architecting robust, deterministic logic for Cross-Domain Solutions (CDS)—including complex state machines, message inspection and data filtering engines, custom AXI streaming/memory-mapped interfaces, and modular IP cores.

The ideal candidate is a disciplined firmware engineer who treats FPGA hardware development with modern software engineering rigor: maintaining reproducible, Git-tracked project configurations via TCL scripts, packaging reusable IP blocks with Vivado IP Packager, and integrating block designs in Vivado IP Integrator. This position is open to remote candidates who possess the drive, organizational discipline, and proven track record to get up to speed quickly and execute independently.
• Designing, implementing, simulating, and synthesizing robust, synchronous digital logic using VHDL and/or SystemVerilog targeting AMD/Xilinx Zynq UltraScale+ MPSoC devices
• Architecting and implementing high-throughput, rule-based data inspection logic, protocol parsers, and custom finite state machines (FSMs) to support cross-domain guard and security filtering functions
• Creating, maintaining, and integrating modular IP cores using Vivado’s IP Integrator and IP Packager, ensuring clean abstraction and modularity across the system block design
• Designing and verifying standard AXI interfaces (AXI4, AXI4-Lite, AXI4-Stream) to facilitate low-latency control and status messaging between the FPGA fabric (PL) and the ARM Processing System (PS)
• Maintaining FPGA projects within Git, utilizing automated TCL scripts for deterministic project regeneration, synthesis, implementation, and bitstream generation
• Authoring rigorous behavioral and post-synthesis testbenches to validate corner cases, packet boundary conditions, state-machine transitions, and timing closure
• Coordinating with NRL researchers, systems engineers, security certifiers, and embedded software teams on interface control documents (ICDs), register memory maps, and verification plans

Requirements
• Bachelor’s degree in electrical engineering, computer engineering, computer science, or related technical field, plus eight or more years of professional experience in FPGA logic design and firmware development (or an equivalent combination of education and demonstrable experience)
• Demonstrable proficiency in VHDL or Verilog/SystemVerilog with a solid foundation in synchronous design practices, robust finite state machine (FSM) implementation, clock domain crossing (CDC) management, and static timing analysis
• Hands-on experience with the AMD/Xilinx Vivado Design Suite, specifically including extensive use of IP Integrator (block designs) and standard implementation/timing closure flows
• Practical experience designing, integrating, and debugging AXI protocols (AXI4-Lite, AXI4-Stream, or AXI4-Memory Mapped) for on-chip communications
• Demonstrable experience managing FPGA source code and project environments in Git, including the use of TCL scripting to build and recreate Vivado projects headlessly
• Proven ability to work autonomously and drive firmware tasks to completion in a remote or distributed team setting, with clear written and verbal technical communication skills
• Active DoD Secret clearance (Ability to obtain or possession of a current Navy Common Access Card / CAC)

Desired Skills
• Experience with VHDL and SystemVerilog or Verilog for logic design and verification
• Experience implementing or interfacing with high-speed serial protocols, specifically PCI Express (PCIe) or multi-gigabit transceivers
• Familiarity with the ARM Processing System (PS) side of Zynq UltraScale+ devices (e.g., bare-metal C drivers, PetaLinux, or register interface bring-up)
• Familiarity with anti-tamper, secure boot, hardware root of trust, and programming eFUSE / BBRAM for bitstream encryption and authentication
• Prior experience using Vivado IP Packager to bundle custom VHDL/SystemVerilog entities into standalone, reusable AXI IP catalog blocks
• Familiarity with PCB schematic review and high-speed board layout considerations (pin constraints, signal integrity, power rail sequencing) from an FPGA designer's perspective
• Experience with automated verification frameworks or Python/Bash scripting for automated regression test runs
